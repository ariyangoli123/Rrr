# TV Candle Hider — افزونه مخفی‌کردن کندل‌ها در تریدینگ‌ویو

کندل‌های بعد از یک تاریخ دلخواه را روی چارت تریدینگ‌ویو مخفی می‌کند و بعد با هر کلیک یک کندل را نشان می‌دهد (برای تمرین بک‌تست دستی).

## نصب (Chrome / Edge / Brave)
1. پوشه `tv-candle-hider` را دانلود کنید.
2. به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. روی **Load unpacked** بزنید و این پوشه را انتخاب کنید.
4. صفحه چارت تریدینگ‌ویو (`tradingview.com/chart/...`) را باز یا رفرش کنید.

## استفاده
- در پنل شناور، تاریخ را انتخاب کنید و **مخفی کن** را بزنید.
- **کندل بعدی** (یا `Shift+→`): یک کندل از تایم‌فریم فعلی ظاهر می‌شود.
- **یک کندل عقب** (یا `Shift+←`): یک کندل دوباره مخفی می‌شود.
- اگر تایم‌فریم را عوض کنید، پرده با کندل‌های تایم‌فریم جدید هماهنگ می‌شود. مثلاً روی ۱ ساعته ۴ کندل جلو بروید و بعد به ۴ ساعته بروید: همان نقطه حفظ می‌شود. کندل ۴ ساعته‌ای که هنوز کامل نشده، مخفی می‌ماند.
- **نمایش همه**: پرده برداشته می‌شود.

## اندیکاتورهای خود افزونه
در پنل بخش «اندیکاتورها» هست. نوع را انتخاب کنید، اگر خواستید پارامترها را عوض کنید (با کاما جدا کنید، مثلاً `12, 26, 9`) و + بزنید.

| روی چارت | پنجره جدا |
|---|---|
| Moving Average (MA)، EMA، WMA | RSI |
| Bollinger Bands، Donchian Channels | MACD |
| VWAP | Stochastic |
| Ichimoku Cloud | CCI |
| Supertrend | Williams %R |
| Parabolic SAR | ATR |
| Volume | DMI (ADX، +DI، -DI) |
| | OBV |

- شکل نمایش مثل خود تریدینگ‌ویو است: همان رنگ‌ها و سبک خطوط پیش‌فرض، سطح‌های ۷۰/۳۰ و ناحیه رنگی RSI، هیستوگرام چهاررنگ MACD، ابر سبز/قرمز ایچیموکو، علامت‌های + برای SAR.
- نام اندیکاتور و مقدارهایش بالا سمت چپ هر پنجره نشان داده می‌شود و با حرکت موس، مقدار همان کندل را نشان می‌دهد. روی محور قیمت هم برچسب رنگی آخرین مقدار هست.
- فرمول‌ها با کتابخانه technicalindicators مقایسه شده‌اند و مقدارها یکی است.
- هر اندیکاتور را می‌شود چندبار اضافه کرد، با تیک موقتاً مخفی کرد، رنگ خط اصلی‌اش را عوض کرد یا با × حذف کرد.
- این اندیکاتورها جزو اندیکاتورهای تریدینگ‌ویو نیستند. خود افزونه آن‌ها را حساب می‌کند و فقط از کندل‌های قبل از پرده استفاده می‌کند، پس آینده را لو نمی‌دهند.
- **پنجره‌های جدا روی پایین چارت می‌افتند**، چون افزونه نمی‌تواند پنجره اصلی تریدینگ‌ویو را کوچک کند. برای اینکه کندل‌ها زیر آن‌ها نروند، در تنظیمات چارت (Settings ← Canvas یا Scales) **Margins ← Bottom** را بیشتر کنید (مثلاً ۴۰٪ برای دو پنجره).
- زیر پنل، متن «داده: exportData» یا «داده: internals» نشان می‌دهد داده کندل‌ها از کدام راه گرفته شده. اگر خطای قرمز دیدید، همان را بفرستید.
- مقیاس محور قیمت باید Regular یا Log باشد (درصدی پشتیبانی نمی‌شود). VWAP هر روز به وقت UTC از نو شروع می‌شود.

## چطور کار می‌کند
چارت تریدینگ‌ویو روی `<canvas>` کشیده می‌شود، پس کندل‌ها عنصر HTML نیستند و با ویرایش HTML حذف نمی‌شوند.
این افزونه یک لایه HTML کاملاً مات روی چارت می‌گذارد که از کندل انتخابی تا لبه راست چارت را می‌پوشاند (پنجره اندیکاتورها هم پوشانده می‌شود).
جای دقیق کندل را از API داخلی صفحه (`TradingViewApi`) می‌گیرد و در هر فریم به‌روز می‌کند، پس با زوم، اسکرول و تغییر تایم‌فریم جابه‌جا می‌شود.
این لایه موس را هم می‌گیرد، پس با بردن موس روی ناحیه مخفی، نمودار یا قیمت کندل‌های مخفی دیده نمی‌شود.

## محدودیت‌ها
- در ناحیه مخفی نمی‌توانید چارت را با موس بکشید یا زوم کنید؛ این کار را در ناحیه قابل‌دیدن انجام دهید.
- **لبه امن** فقط وقتی اثر دارد که تریدینگ‌ویو جای دقیق کندل را ندهد؛ آن‌وقت لبه پرده نیم کندل به چپ می‌رود تا چیزی از آینده دیده نشود.
- مقیاس خودکار محور قیمت ممکن است سقف و کف کندل‌های مخفی را لو بدهد. بهتر است Auto scale را خاموش کنید (کلیک راست روی محور قیمت).
- اگر رنگ پرده با پس‌زمینه یکی نبود، از گزینه «رنگ پرده» درستش کنید.
- تاریخ به وقت سیستم شما وارد می‌شود.
- `TradingViewApi` رسمی نیست و ممکن است تریدینگ‌ویو آن را تغییر دهد.
- خود تریدینگ‌ویو هم قابلیت **Bar Replay** را دارد که همین کار را رسمی انجام می‌دهد (در نسخه رایگان محدود است).
